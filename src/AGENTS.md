# Site UI

- Routes export `Route = createFileRoute(...)`; keep title/description in their
  `head` using `published` content. The root shell owns header/footer, CSS, and
  `<main id="main">`; preserve the skip link and semantic heading hierarchy.
- Use TanStack `Link` for internal navigation, anchors for external/mail links.
- Components consume `published` lines via `.toText()`, not literal visible copy.
  Follow `src/content/AGENTS.md` when changing the ledger.
- Product cards without a confirmed URL show their development status. Never invent a
  product link; add one to the ledger only when Carlos supplies it.
- Contact buttons use Carlos's existing email; `/contact` redirects to `/services`.
  Never invent a booking URL or claim scheduling works.
- Keep responsive styles in `styles/app.css`; verify desktop and mobile output.
- `routeTree.gen.ts` is generated by TanStack during dev/build; do not edit it.
