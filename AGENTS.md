# Alfaro Labs site

Public site for Alfaro Labs. Domain `alfarolabs.com`.

## Stack

TanStack Start (React, TypeScript) with the Cloudflare Workers adapter.

```
npm run dev
npm run typecheck
npm run build
npm run smoke
```

## Do not

- Add Clerk, a chat widget, or D1.
- Invent client names or metrics.
- Run `wrangler deploy`. CI does not deploy.
